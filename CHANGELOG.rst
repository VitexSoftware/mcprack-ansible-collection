==========================================
vitexsoftware.mcprack Release Notes
==========================================

.. contents:: Topics

v1.0.0
======

Release Summary
----------------

Initial release.

New Modules
------------

- vitexsoftware.mcprack.mcprack_server - Manage mcprack catalog servers.
- vitexsoftware.mcprack.mcprack_user - Manage mcprack local user accounts.
- vitexsoftware.mcprack.mcprack_user_access - Manage per-user server allow/deny.
- vitexsoftware.mcprack.mcprack_user_selection - Manage a user's pre-selected servers.
- vitexsoftware.mcprack.mcprack_user_override - Manage per-user per-server overrides.
- vitexsoftware.mcprack.mcprack_user_config - Fetch a user's rendered client config.
- vitexsoftware.mcprack.mcprack_secret - Manage a catalog server's secret env keys.
- vitexsoftware.mcprack.mcprack_template - Manage admin server-bundle templates.
- vitexsoftware.mcprack.mcprack_template_apply - Apply a template to a user.

New Roles
----------

- vitexsoftware.mcprack.app - Install and configure the mcprack application.
